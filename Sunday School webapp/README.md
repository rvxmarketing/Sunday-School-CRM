# Escuela Dominical · Estaca — prototipo visual

- `index.html`: estructura de la interfaz.
- `styles.css`: gradientes, tarjetas, diseño adaptable a móviles.
- `app.js`: navegación de demostración, búsqueda, filtros y gráficas.

## Uso
Extrae el ZIP y abre `index.html` en Chrome o Firefox. Las gráficas y la fuente Inter se cargan desde CDN, así que requieren internet.

## Importante
Es una demostración con datos ficticios. No está conectada a Google Sheets, Apps Script ni a autenticación. No introduzcas datos reales de miembros.
